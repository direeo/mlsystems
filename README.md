# ML Prediction Systems - CSC415_22CG031908

## Overview
This project contains 4 machine learning prediction systems for CSC415 coursework:

1. **6a_house_price/** - House Price Prediction (California Housing)
2. **6b_titanic/** - Titanic Survival Prediction
3. **6c_breast_cancer/** - Breast Cancer Diagnosis Prediction
4. **6d_wine_origin/** - Wine Cultivar Origin Prediction

## Requirements
- **Python 3.9 - 3.12** (TensorFlow does NOT support Python 3.13+)
- TensorFlow, scikit-learn, Flask, Flask-CORS

## Quick Setup

### Step 1: Install Dependencies
```bash
pip install -r requirements.txt
```

### Step 2: Train Models (Generates model.h5 files)
Run these commands from the project root:

```bash
# Train House Price Model
cd 6a_house_price
python train_model.py
cd ..

# Train Titanic Model
cd 6b_titanic
python train_model.py
cd ..

# Train Breast Cancer Model
cd 6c_breast_cancer
python train_model.py
cd ..

# Train Wine Origin Model
cd 6d_wine_origin
python train_model.py
cd ..
```

### Step 3: Run Any Application
```bash
cd 6a_house_price
python app.py
```
Then open http://localhost:5000 in your browser.

## Port Configuration
- 6a_house_price: Port 5000
- 6b_titanic: Port 5001
- 6c_breast_cancer: Port 5002
- 6d_wine_origin: Port 5003

## Files Per System
Each folder contains:
- `index.html` - Web interface
- `app.py` - Flask backend
- `model.h5` - Trained Keras model (generated by train_model.py)
- `train_model.py` - Model training script
- `scaler.pkl` - Feature scaler (generated by train_model.py)
